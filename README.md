# North Star Bakery

Touchstone 3 builds on the four North Star Bakery pages from Touchstone Task 2.
All four pages share the external stylesheet, `styles.css`. The image and audio
assets are from Sophia's North Star Bakery media pack. Sample business details
are fictional. The contact form demonstrates browser validation.

## Preview in GitHub Codespaces

1. Put the contents of this project folder at the root of the public GitHub
   repository, keeping the `media` folder intact.
2. In the repository, select **Code**, open **Codespaces**, and create or open a
   codespace for the branch containing the files.
3. In the Codespaces terminal, run `python3 -m http.server 8000`.
4. Under **Ports**, open the forwarded URL for port 8000. Use that URL for the
   template's preview field. If the course requires the preview link to open
   without an account, check port visibility and test in a private window.
5. Copy the public repository URL into the separate repository field.
